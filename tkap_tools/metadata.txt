description=Field tools for the Türkmen-Karahöyük Archaeological Project: stratigraphic phasing, section drawing, and GNSS survey point conversion.
about=The TKAP QGIS tools. Three tools live under the TKAP Tools
    menu:
    .
    Stratigraphic Phasing: splits a layer of Stratigraphic Units into one layer
    per phase for a chosen excavation field, parsing the delimited space_phase
    attribute. An SU spanning several phases is written into every phase layer it
    belongs to. Output goes to live filtered layers, scratch layers, or a
    GeoPackage. A second action exports one phase plan per layer from a print
    layout you designed.
    .
    Section Drawing: draw a section trace in plan view, pick the SUs that cross
    it, place a photo of the excavation wall using surveyed control points, and
    digitise SU polygons against absolute elevation. Outputs a measured drawing
    and a wireframe-over-photo version, both with an elevation axis. Newer than
    the other two tools; treat as beta.
    .
    Survey Points to Polygons: reads Emlid GNSS point exports and connects each
    outline's points in increment order into a closed polygon. Handles both SU_
    points and F_ feature points in one pass, each against its own target layer,
    either replacing geometry on the existing layers or building onto new
    temporary ones. An outline shot out of perimeter order is reordered to
    uncross itself before the polygon is built.
    .

changelog=1.4.1
    - Fix: the wireframe backdrop colour appeared to do nothing. It was being
      drawn correctly, but a placed ortho is axis-aligned and fills the frame,
      so the backdrop sat behind it with nothing to show through. There is now
      a "Fade the photo" setting next to it, which knocks the photo back
      towards the backdrop so the outlines read over a bright wall - and which
      is what makes the backdrop colour mean anything.
    - Fix: most of the export controls did not redraw the preview. The frame
      box, the height-line interval, every label and caption control and all
      the wireframe colours changed the output without changing the picture of
      it. They all redraw now. Resolution deliberately does not, since the
      preview renders at its own.
    - Section Drawing: the unit table's columns can be dragged to any width,
      and reordered. They were fixed to their contents or stretched, which on a
      seven-column table in a narrow dock meant the column you needed to read
      was the one you could not widen.
    1.4.0
    - Section Drawing: units can be given a name of their own, and each unit
      decides for itself what the drawing writes on it. Type a name into the new
      Label column - "rocky fill" rather than a number - and set the Shows
      column to Number, Label, Number and label, or Nothing. Per unit, not per
      drawing, because a section usually wants numbers throughout with two or
      three units named and a thin lens left blank.
    - Section Drawing: labels can be sized, or turned off altogether for a clean
      unlabelled plate. They were fixed at 8 pt and always on.
    - Section Drawing: the wireframe's outline colour, outline width and
      backdrop colour are settable. Yellow on near-black suits most excavation
      photographs and vanishes over a pale sunlit wall.
    - Section Drawing: the caption under the title can be typed by hand, or
      left off. By default it now reads which way the section is viewed and at
      what scale - "Looking north - 1:20" - replacing the line that restated
      the trace's name, azimuth and length.
    - Section Drawing: the export dialog remembers what you used last, per
      output kind, so page size, scale, resolution and colours no longer reset
      on every export. Title and caption are deliberately not remembered, since
      they name one particular section.
    1.3.0
    - Fix: Section Drawing's "Remove" did not remove. It deleted the unit's
      polygon straight through the data provider, underneath the edit session
      the drawing layer is held in, so the layer went on showing it and undo
      knew nothing about it - and it left the unit in the roster, looking like
      it had failed to draw. Removing now goes through the edit session (so
      Ctrl+Z works) and takes the unit out of the list as well.
    - Section Drawing: resizing the frame now re-decides which units the
      section holds. Units the frame takes in are seeded, and units it no
      longer reaches are dropped - but only while they are still untouched
      seeds. Anything drawn on or given a height is kept whatever the frame
      does, and named in the message, because tidying a list is never worth
      losing someone's tracing.
    - Section Drawing: every part of the panel collapses now, not just the
      frame, and each remembers whether you left it open.
    - Section Drawing: "Re-seed" has a button. It was written and documented
      but never wired to anything, so there was no way to put a fresh seed box
      back after editing one.
    1.2.1
    - Fix: reopening a saved section then pressing "Add unit..." failed with
      "This session has no source SU layer to add from". A saved section carries
      only its drawing, and nothing recorded which SU layer it was drawn from,
      so after a QGIS restart there was nothing to add units from and no way to
      say what it should be.
    - Saved sections now record their SU layer, and reopening looks it up again
      by id, then by data source, then by name - so a rebuilt project, a
      renamed layer or moved data still finds it. Sections saved before this
      release have nothing recorded, and are handled the same way as a layer
      that cannot be found.
    - Section Drawing: a "Data sources" section in the panel shows which SU
      layer the section reads from and lets it be changed at any time, which
      also repoints the symbology and the export. "Add unit..." now offers to
      pick a layer instead of refusing.
    - Section Drawing: the "Section frame" panel section is collapsible and
      starts collapsed, giving the height back to the SU roster. Both panel
      sections remember whether you left them open.
    1.2.0
    - Section Drawing: the section frame can be resized while you draw. Press
      "Resize on canvas" in the panel and drag its corners or edges, or type
      exact chainage and elevation limits. The frame is what the exported figure
      covers, so cropping it crops the drawing - which means an ortho that
      covers more wall than the section no longer has to be cut down first.
      "Fit to photo" and "Reset to trace" are there for the common cases, and a
      cropped frame is kept when the section is saved and reopened.
    - Section Drawing: the control-point photo is now sharp when you zoom in.
      The full-resolution pixels for whatever you are looking at are read on
      demand and drawn over the overview, so a nailhead resolves instead of
      dissolving into the downsampled preview it used to be clicked on. Memory
      does not grow with the size of the ortho.
    1.1.1
    - Fix: the Survey Points to Polygons window opened taller than the screen
      once both point types had a target row, putting Run and Close off the
      bottom with no way to reach them. The settings now sit in a scrolling
      panel, the log and both buttons stay outside it and are always visible,
      and the window opens no larger than the display it lands on.
    1.1.0
    - Emlid to SU is now Survey Points to Polygons, and builds feature outlines
      as well as SU outlines. F_ points (F_[Field].[Feature]-[n]) are read
      alongside SU_ points and written to the Features layer, matched on the
      feature number against its Feature field.
    - One run does both: each point type has its own target layer and number
      field, and either can be switched off. Pointing both at the same layer is
      refused rather than filing feature numbers as SU numbers.
    - Crossover check. An outline whose points were shot out of perimeter order
      makes a self-crossing "bowtie" polygon; it is now reordered to uncross
      itself before the polygon is built, changing the recorded order as little
      as possible so concave outlines stay concave. Each fix is logged with the
      increments involved, and QC layers still show the shots as recorded so the
      result can be checked against them. 74 of the 486 outlines in the seasons
      archive self-cross.
    - Feature-number field on the target layer defaults to Feature, SU to SU,
      and each target layer is preselected by which of those fields it carries.
    - Temporary-layer mode builds one layer per point type, each carrying the
      number, the vertex count, and how many crossings were undone.
    - QC layers are named QC_SU_<n> / QC_F_<n> and carry TYPE and NUMBER, so SU
      55 and Feature 55 no longer collide.
    1.0.0
    - First release.
