TKAP Tools

QGIS tools for Türkmen-Karahöyük excavation data.

Emlid to SU

Turn GNSS point exports into SU polygons.

Stratigraphic Phasing

Split SUs into one layer per phase, and export phase plans.

Section Drawing

Draw sections over a rectified photo of the wall.

Install

Add the repository once. Updates then come through the Plugin Manager.

https://amcgallian.github.io/tkap-qgis/plugins.xml
  1. Plugins → Manage and Install Plugins → Settings
  2. Under Plugin Repositories, click Add…
  3. Name it TKAP, paste the URL above, click OK
  4. Go to the All tab, search TKAP Tools, install

For update notifications, check Check for updates on startup on that same Settings tab and set how often you want it to look.

Or take the zip from the latest release and use Install from ZIP. You'll have to repeat that by hand for each update.

Needs QGIS 3.34 or newer.

Where the tools live

One entry in the Plugins menu, TKAP Tools, with every action under it. The toolbar button opens the same menu.

If a tool is missing

The tools load separately, so one failing doesn't stop the others. If an action isn't in the menu, open View → Panels → Log Messages and read the TKAP Tools tab. The reason is there. Open an issue with what it says.
