# TKAP Tools

QGIS plugin for the Türkmen-Karahöyük Archaeological Project.

| Tool | What it does |
|---|---|
| **Emlid to SU** | Builds SU polygons from Emlid GNSS point exports. |
| **Stratigraphic Phasing** | Splits SUs into one layer per phase, and exports phase plans. |
| **Section Drawing** | Draws sections over a rectified photo of the wall. |

Requires QGIS 3.34 or newer.

## Install

Add this repository under *Plugins → Manage and Install Plugins → Settings →
Plugin Repositories → Add…*:

```
https://amcgallian.github.io/tkap-qgis/plugins.xml
```

Then install **TKAP Tools** from the *All* tab. Updates come through the Plugin
Manager after that.

Or take the zip from the
[latest release](https://github.com/amcgallian/tkap-qgis/releases/latest) and use
*Install from ZIP*.
